# Geometric Library

## Общее описание

Geometric Library — библиотека на Python для вычисления площади и периметра геометрических фигур.

В проекте реализованы вычисления для:

- круга.
- квадрата.

## Круг

Функции для работы с кругом находятся в файле `circle.py`.

### Площадь круга

Функция `area(r)` вычисляет площадь круга по формуле:

`S = πr²`

Параметры:

- `r` (`int | float`) — радиус круга.

Возвращаемое значение:

- `float` — площадь круга.

Пример:

```python
import circle

result = circle.area(2)
print(result)
```

Результат:

```text
12.566370614359172
```

### Периметр круга

Функция `perimeter(r)` вычисляет длину окружности по формуле:

`P = 2πr`

Параметры:

- `r` (`int | float`) — радиус круга.

Возвращаемое значение:

- `float` — длина окружности.

Пример:

```python
import circle

result = circle.perimeter(2)
print(result)
```

Результат:

```text
12.566370614359172
```

## Квадрат

Функции для работы с квадратом находятся в файле `square.py`.

### Площадь квадрата

Функция `area(a)` вычисляет площадь квадрата по формуле:

`S = a²`

Параметры:

- `a` (`int | float`) — длина стороны квадрата.

Возвращаемое значение:

- `int | float` — площадь квадрата.

Пример:

```python
import square

result = square.area(2)
print(result)
```

Результат:

```text
4
```

### Периметр квадрата

Функция `perimeter(a)` вычисляет периметр квадрата по формуле:

`P = 4a`

Параметры:

- `a` (`int | float`) — длина стороны квадрата.

Возвращаемое значение:

- `int | float` — периметр квадрата.

Пример:

```python
import square

result = square.perimeter(2)
print(result)
```

Результат:

```text
8
```

## Модульное тестирование

Для проверки всех четырёх функций добавлены `test_circle.py` и `test_square.py`.
Каждый файл содержит класс, наследующий `unittest.TestCase`, и 10 тестов.
Проверяются ноль, единица, положительное целое число, дробное и малое
положительное значение. Ожидаемые результаты заданы заранее числовыми
константами. Тесты используют стандартный модуль `unittest`; установка
сторонних пакетов не требуется.

Из корневого каталога `geometric_lib` выполните:

```bash
python3 -m unittest discover -v
```

На Windows можно использовать `py -m unittest discover -v`.

План тестирования, контрольные данные, критерии приёмки и результаты описаны
в [TESTING.md](TESTING.md).
